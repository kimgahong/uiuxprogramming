# RunMate · 맞춤형 러닝 코치

러닝 목표에 맞는 러닝 세션을 설정하고 러닝 습관을 꾸준히 이어가도록 돕는 한 페이지 웹 서비스입니다.

## 배포 주소

https://kimgahong.github.io/uiuxprogramming/

## 저장소 주소

https://github.com/kimgahong/uiuxprogramming

## 사용자

- 러닝을 처음 시작하는 사람
- 러닝을 꾸준히 이어가고 싶은 사람

## 서비스 목적

러닝 목표와 운동 가능 시간에 맞는 러닝 세션을 설정해서 무리하지 않고 꾸준한 러닝 습관을 만들도록 돕는다.

## 완료할 핵심 행동

**안전 안내를 확인한 뒤 러닝 세션(이름, 러닝 시간, 중간 휴식)을 설정하고, 그 설정으로 인터벌 러닝 세션을 실행해 결과를 확인한다.**

## 사용자 흐름

1. **서비스 소개**에서 RunMate가 어떤 서비스인지 확인한다.
2. **러닝 기능** 탭(맞춤형 러닝 계획 / 단계별 러닝 훈련 / 러닝 피드백)을 눌러 기능을 살펴본다.
3. **이용 방법**에서 이용 순서를 확인한다.
4. **러닝 코치 이용 설정**에서 테마와 러너 닉네임을 정하고, `러닝 전 준비운동과 안전 안내` 체크박스를 선택한다.
5. `러닝 설정 시작하기`를 누르면 **러닝 안전 안내** 다이얼로그가 열린다.
6. `확인하고 설정 시작하기`를 누르면 **러닝 세션 설정** 영역이 나타난다.
   1. 1 · 정보: 세션 이름을 입력한다.
   2. 2 · 조건: 러닝 시간(10분 / 20분 / 30분)과 중간 휴식(1회 / 2회 / 3회)을 고른다.
   3. 3 · 확인: 입력한 내용을 요약 화면에서 확인한다.
7. `설정 완료하기`를 누르면 완료 화면이 보인다. `다시 설정하기`로 처음부터 다시 설정할 수 있다.
8. **(중간고사 추가)** `이 설정으로 러닝 시작하기`를 누르면 4 · 러닝 단계로 넘어간다.
   1. 준비: 자동으로 만든 구간 타임라인을 보고 음성 안내·진동·시연 배속을 고른다.
   2. `러닝 시작` → 3·2·1 카운트다운 → 구간별 타이머로 세션이 진행된다.
   3. 마지막 구간이 끝나면 완주 결과, 중간에 그만두면 중단 결과 또는 결과 없음 안내가 보인다.
9. 필요하면 **러닝 소식 받기**에 이메일을 입력해서 소식을 신청한다.

## 인터랙션 시나리오

| 상황 | 사용자 행동 | 화면 변화 |
| --- | --- | --- |
| 테마 변경 | `어두운 테마로 바꾸기`를 누른다. | `body`에 `dark` 클래스가 붙고 버튼 문구가 `밝은 테마로 바꾸기`로 바뀐다. |
| 닉네임 입력 | 러너 닉네임을 입력한다. | 글자 수가 `0 / 10` 형식으로 바로 바뀌고, 10자를 넘으면 잘린다. |
| 안전 안내 동의 | 체크박스를 선택한다. | 안내 문구가 `확인이 완료되었습니다. 러닝 설정을 시작할 수 있습니다.`로 바뀌고 `러닝 설정 시작하기` 버튼이 활성화된다. |
| 기능 탭 | 탭을 누른다. | 누른 탭만 선택 상태(`aria-selected="true"`)가 되고 연결된 패널 하나만 보인다. |
| 다이얼로그 열기 | `러닝 설정 시작하기`를 누른다. | `<dialog>`가 모달로 열리고 뒤 화면이 어두워진다. |
| 다이얼로그 취소 | `돌아가기`를 누르거나 Esc를 누른다. | 다이얼로그가 닫히고 동의 체크가 풀려서 시작 버튼이 다시 비활성화된다. |
| 다이얼로그 확인 | `확인하고 설정 시작하기`를 누른다. | 러닝 세션 설정 영역이 나타나고 화면이 그 위치로 스크롤되며 세션 이름 입력칸에 포커스가 간다. |
| 세션 이름 오류 | 이름을 비우거나 공백만 넣고 `러닝 조건 선택하기`를 누른다. | `러닝 세션 이름을 입력해주세요.` 오류 문구가 나오고 입력칸 테두리가 빨갛게 바뀌며 다음 단계로 넘어가지 않는다. |
| 러닝 시간 선택 | 슬라이더를 움직인다. | 옆의 값이 `10분` / `20분` / `30분`으로 바로 바뀐다. |
| 중간 휴식 | `중간 휴식 설정`을 체크한다. | 휴식 횟수(1회 / 2회 / 3회, 기본 2회) 선택지가 나타난다. 체크를 풀면 사라진다. |
| 요약 확인 | `내용 확인하기`를 누른다. | 세션 이름, 러닝 시간, 중간 휴식(설정하지 않았으면 `설정하지 않음`)이 요약된다. |
| 이전 단계 | `이전` 또는 `수정하기`를 누른다. | 앞 단계로 돌아가고, 입력했던 값은 그대로 남아 있다. |
| 설정 완료 | `설정 완료하기`를 누른다. | `러닝 세션 설정이 완료되었습니다.` 완료 화면이 보인다. |
| 다시 설정 | `다시 설정하기`를 누른다. | 모든 값이 처음 상태(이름 비움, 20분, 휴식 없음)로 돌아가고 1단계가 보인다. |
| 소식 신청 | 이메일을 입력하고 `러닝 소식 신청하기`를 누른다. | `runner@email.com로 신청이 완료되었습니다.`가 보이고 버튼이 `신청 완료`로 바뀌며 비활성화된다. 이메일이 비어 있거나 형식이 틀리면 브라우저 검사 안내가 뜨고 신청되지 않는다. |

## 중간고사: 인터벌 러닝 세션 플레이어

### 새로 추가한 기능

7주차에 설정한 세션 이름·러닝 시간·휴식 횟수로 **워밍업 걷기 → 달리기 → 걷기 휴식 → … → 쿨다운 걷기** 구간을 자동으로 만들고, 타이머와 음성·진동 안내로 실제 러닝 세션을 진행한 뒤 완주·중단 결과와 다음 세션 제안을 보여 주는 플레이어를 추가했다. 7주차는 계획을 세우는 데서 끝났지만(안전 안내에도 "실제 운동이 시작되지는 않습니다"라고 적혀 있었다), 이제 설정한 계획을 그대로 실행할 수 있다.

### 7주차 흐름과의 연결

흐름의 **끝**에 이어 붙였다.

```
안전 안내 dialog → 1 정보 → 2 조건 → 3 확인 → 설정 완료
                                               └ [이 설정으로 러닝 시작하기]
                                                    → 4 러닝: 준비 → 3·2·1 → 진행 → 완주 / 중단 / 결과 없음
```

- 진행 표시에 `4 · 러닝` 칸을 추가했다.
- 준비 화면 제목에 7주차 세션 이름이 들어가고, 총 시간·휴식 횟수·구간이 7주차 설정값(`sessionData`)으로 만들어진다.

### 구간 자동 생성 규칙

내부 계산은 모두 초 단위 정수로 한다.

| 항목 | 값 |
| --- | --- |
| 워밍업 걷기 / 쿨다운 걷기 | 각 2분 (10분 세션은 각 1분) |
| 걷기 휴식 | 1회당 1분 |
| 휴식 횟수 | 7주차에서 `중간 휴식 설정`을 체크했을 때만 선택한 1~3회, 체크하지 않으면 0회 |
| 달리기 | 남은 시간을 (휴식 횟수 + 1)개로 나눔. 나누고 남은 초는 마지막 달리기에 더해 총합을 설정 시간과 정확히 맞춤 |
| 자동 조정 | 달리기 한 구간이 **2분보다 짧아지면** 휴식을 1회씩 줄이고 이유를 노란 안내 상자로 보여 줌 |

| 설정 | 만들어지는 구간 |
| --- | --- |
| 20분 · 휴식 2회 | 워밍업 2분 · 달리기 4분 40초 · 휴식 1분 · 달리기 4분 40초 · 휴식 1분 · 달리기 4분 40초 · 쿨다운 2분 |
| 30분 · 휴식 없음 | 워밍업 2분 · 달리기 26분 · 쿨다운 2분 |
| 10분 · 휴식 3회 | 휴식 3회면 달리기가 1분 15초라 **2회로 조정** → 워밍업 1분 · 달리기 2분 ×3 · 휴식 1분 ×2 · 쿨다운 1분 |

타임라인은 구간 종류별 색(걷기 = 그린, 달리기 = 레드, 휴식 = 블루)의 막대를 시간에 비례한 길이로 그리고, 아래에 구간 이름과 시간 목록을 함께 보여 준다. 색만으로 구분하지 않도록 목록에 `진행 중 / 완료 / 건너뜀`도 글자로 표시한다.

### 사용자 행동과 조건 검사

| 사용자 행동 | 확인하는 조건 | 성공 반응 | 다른 분기의 반응 | 다음 행동 |
| --- | --- | --- | --- | --- |
| `이 설정으로 러닝 시작하기` | 휴식 때문에 달리기가 2분보다 짧아지는가 | 준비 화면에 세션 이름·총 시간·휴식·구간 타임라인 | 짧아지면 휴식을 줄이고 `…휴식을 2회로 줄였어요.` 안내 (**자동 조정**) | `러닝 시작` / `이전` |
| 음성 안내·진동 선택 | 브라우저가 Web Speech API, 진동(터치 기기 + `navigator.vibrate`)을 지원하는가 | 선택한 안내가 구간 전환 때 동작 | 지원하지 않으면 체크박스가 비활성화되고 `이 브라우저는 음성 안내를 지원하지 않아요.` / `진동을 지원하는 휴대폰에서만 사용할 수 있어요.` 안내. 세션은 그대로 진행 | `러닝 시작` |
| `러닝 시작` | – | 실제 3초 카운트다운 후 첫 구간 시작 | `시작 취소` 또는 탭 이탈 시 준비 화면으로 돌아가고 `시작을 취소했어요.` 안내 (**취소**) | `러닝 시작` |
| 진행 중 대기 | 현재 구간의 남은 시간이 0이 되었는가 (실제 경과 시간 × 배속, `Date.now()` 기준) | 다음 구간으로 넘어가고 배경색·링·타임라인·상태 문구가 바뀌며 음성·진동 안내 | 마지막 구간이 끝나면 완주 결과 | – |
| `일시정지` / `계속` | 현재 진행 중인가 / 일시정지 중인가 | 시간이 멈추고 화면이 회색으로, `계속`을 누르면 남은 시간부터 이어짐 | – | `계속` / `다음 구간으로` / `그만두기` |
| 다른 탭으로 이동 | `visibilitychange`로 화면이 숨겨졌는가 | 자동 일시정지 + `다른 화면으로 이동해서 자동으로 일시정지했어요.` 돌아와도 자동 재개하지 않음 | – | `계속` |
| `다음 구간으로` | 마지막 구간인가 | 현재 구간을 **건너뜀**으로 표시하고 다음 구간 시작 | 마지막 구간이면 결과 화면 | – |
| `그만두기` | – | 확인 dialog가 열리고 타이머가 멈춤 | `계속하기`(또는 Esc) → 원래 상태로 복귀. 원래 일시정지였다면 일시정지 유지 (**취소**) | `계속하기` / `그만두기` |
| dialog의 `그만두기` | 달리기 구간을 1초 이상 진행했는가 | **중단 결과**: 완료 구간, 전체 구간, 건너뛴 구간, 달성률, 다음 세션 제안 | 달리기를 시작하지 않았거나 모두 건너뛰었으면 **결과 없음**: `아직 달리기 구간을 진행하지 않아 기록할 결과가 없어요.` | `같은 설정으로 다시 달리기` / `새 세션 설정하기` |
| `같은 설정으로 다시 달리기` | – | 플레이어 상태만 초기화하고 준비 화면. 7주차 설정과 옵션(음성·배속)은 유지 | – | `러닝 시작` |
| `새 세션 설정하기` | – | 플레이어 + 7주차 설정을 모두 초기화하고 1 · 정보 단계 | – | 세션 이름 입력 |

결과 계산 기준

- **완료 구간**: 시간이 끝까지 흘러 끝난 구간. 건너뛴 구간과 그만둘 때 진행 중이던 구간은 완료에 넣지 않는다.
- **달성률** = 완료 구간 ÷ 전체 구간 (화면에 "구간 기준"이라고 표기). 거리·페이스·칼로리는 측정하지 않으므로 표시하지 않는다.
- **세션 진행 시간 / 달리기 진행 시간**: 배속이 적용된 세션 시간. 배속을 쓰면 결과에 `시연 배속 60배로 진행한 세션 시간이에요.`라고 알려 준다.
- **다음 세션 제안**: 건너뛰지 않고 완주 → 시간을 10분 늘리기(30분이면 휴식 1회 줄이기) / 중단하거나 건너뛰었음 → 같은 시간에 익숙해질 때까지 휴식을 1회 늘리기.

### 상태 관리

`player.state`는 `ready → countdown → running ⇄ paused → finished | stopped | empty` 중 하나다. 상태가 바뀔 때 `updateControls()`가 버튼을 맞춘다 (카운트다운 중에는 `시작 취소`만, 진행 중에는 `일시정지`, 일시정지 중에는 `계속`). 타이머는 `setInterval` 한 개만 쓰고 시작 전에 항상 정리해서 중복 실행되지 않는다. 남은 시간은 매초 바뀌므로 `aria-live`를 끄고, 구간 전환·일시정지 같은 상태 문구 한 곳에만 `aria-live="polite"`를 두었다.

### 디자인 시스템 (그린 중심)

세 가지 색을 같은 비중으로 쓰지 않고, **중립 배경과 카드가 화면 대부분**을 차지하게 했다. 그 위에서 그린이 주요 동작을 맡고, 블루와 레드는 필요한 곳에만 나온다. 색은 모두 `:root`의 CSS 변수(`--color-primary`, `--color-secondary`, `--color-danger`, `--color-bg`, `--color-surface`, `--color-text`, `--color-border` 등)로 관리하고, 다크 테마는 `body.dark`에서 같은 이름의 변수 값만 바꾼다.

| 역할 | 라이트 | 다크 | 쓰는 곳 |

## 7주차 테스트 결과

1100px / 768px / 390px 너비에서 확인했다. 세 너비 모두 콘솔 오류와 가로 스크롤이 없었다.

### 정상

- 체크 전에는 `러닝 설정 시작하기`가 비활성화되어 있고, 체크한 뒤 누르면 다이얼로그가 열린다.
- 세션 이름 `첫 3km 러닝`, 러닝 시간 30분, 중간 휴식 3회로 설정하면 요약에 `첫 3km 러닝 / 30분 / 3회`가 보인다.
- 중간 휴식을 체크하지 않으면 요약에 `설정하지 않음`이 보인다.
- 이메일 `runner@email.com`으로 신청하면 완료 문구가 보이고 버튼이 `신청 완료`로 비활성화된다.

### 오류

- 세션 이름을 비우거나 공백만 넣고 다음을 누르면 오류 문구가 나오고 1단계에 머문다.
- 다이얼로그에서 `돌아가기`를 누르면 동의 체크가 풀리고 시작 버튼이 비활성화되며 설정 영역은 열리지 않는다.
- 이메일을 비우거나 `abc`처럼 형식이 틀리게 입력하면 신청되지 않는다.

### 이전

- 요약 화면에서 `수정하기`를 누르면 2단계로 돌아가고 슬라이더 값(30분)과 휴식 체크가 그대로 남아 있다.
- 2단계에서 `이전`을 누르면 1단계로 돌아가고 세션 이름이 그대로 남아 있다.

### 완료

- `설정 완료하기`를 누르면 `러닝 세션 설정이 완료되었습니다.` 화면이 보인다.
- `다시 설정하기`를 누르면 이름이 비워지고 20분, 휴식 없음으로 초기화된 1단계가 보인다.
